Contagem de conflitos

Mesma linha

Os valores das duas colunas são iguais.

tabuleiro[c1] == tabuleiro[c2]

Mesma diagonal

A distância entre linhas é igual à distância entre colunas.

|linha1 - linha2| == |c1 - c2|
for coluna1 in range(tamanho):
    for coluna2 in range(coluna1 + 1, tamanho):
        mesma_linha = tabuleiro[coluna1] == tabuleiro[coluna2]

        distancia_colunas = abs(coluna1 - coluna2)
        distancia_linhas = abs(
            tabuleiro[coluna1] - tabuleiro[coluna2]
        )

        if mesma_linha or distancia_colunas == distancia_linhas:
            conflito += 1

Estado vizinho

Um vizinho nasce quando o algoritmo escolhe uma coluna e move sua rainha para outra linha.

25173064
25173264

A cópia preserva o estado atual caso o algoritmo rejeite o movimento.

def gerar_vizinho(tabuleiro):
    vizinho = tabuleiro.copy()

    coluna = random.randrange(len(tabuleiro))
    linha_atual = vizinho[coluna]
    nova_linha = random.randrange(len(tabuleiro))

    while nova_linha == linha_atual:
        nova_linha = random.randrange(len(tabuleiro))

    vizinho[coluna] = nova_linha
    return vizinho

Diferença central

Uma piora temporária pode retirar a busca de uma configuração onde nenhuma melhoria imediata aparece.

Temperatura e decisão

O delta mede a mudança nos conflitos.

delta = conflitos_vizinho - conflitos_atual

Delta menor ou igual a zero: aceita.
Delta positivo: calcula uma chance.

P = e-delta / temperatura
Explora mais Fica exigente 
if delta <= 0:
    atual = vizinho
else:
    probabilidade = math.exp(-delta / temperatura)
    if random.random() < probabilidade:
        atual = vizinho
